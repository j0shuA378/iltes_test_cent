# 🎓 IELTS Master - 雅思全真机考高分备战平台

> 专为雅思考生定制的现代化 Computer-Delivered IELTS (CDI) 全真模拟备考平台。

---

## ✨ 核心特性

- 🖥️ **全真机考体验**：左右分屏、划词高亮笔记、Headings & TFNG 经典题型实时判分换算（Band 等级分）。
- 🎧 **听力真题与精听**：倍速播放、快退 5 秒、S1-S4 答题卡与原文对照定位。
- ✍️ **写作限时与智能评估**：Task 1 & Task 2 官方真题库、实时字数统计与四维评分剖析。
- 🗣️ **口语仿真考场**：Part 2 准备 1 分钟 + 作答 2 分钟提示音，高清录音与复盘。
- 📖 **即时学术词典**：阅读划词沉浸式释义浮窗、英音发音、近义替换、一键收入生词本。
- 🎯 **个人专属适配学习方案**：支持从 4.0 基础到 7.0 梦校高分科学拆解，178 天四阶段进阶路线图与每日任务打卡。
- 🔍 **剑桥 18/19 题库搜寻**：全学科最新考点极速搜索与定位。

---

## 🛠️ 本地启动

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务
npm run dev

# 3. 生产打包
npm run build
```

---

## 🚀 免费一键云端部署 (Vercel / Cloudflare Pages / Netlify)

本项目为纯前端静态应用，可直接导入 Vercel 或 Cloudflare Pages：
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`
已内置 `vercel.json` 与 `public/_redirects` 配置文件，部署后路由与词典反向代理自动生效。
